# Agent Arena

Experiments with AI agents and games.

## Catan AI

Play Catan as one human against three heuristic AI opponents, either in a local
Pygame window or through a VS Code container’s browser desktop.

See the [Catan README](Catan-AI/README.md) for a gameplay screenshot, installation,
controls, rules coverage, and testing instructions. For browser play, follow the
[container guide](Catan-AI/CONTAINER.md).
